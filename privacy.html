Privacy policy

Applies to rednull youtube, the internal YouTube management tool of Rednull Records. Last updated 20 November 2026.

Who uses it

Only the owner of Rednull Records, on the label's own YouTube channels. It is not a public service, and no one else can sign in to it.

What data it accesses

With the owner's permission, through Google's OAuth sign-in, the tool uses the YouTube Data API and the YouTube Analytics API to upload and edit the label's videos, captions, thumbnails and playlists, and to read channel statistics.

Where data is kept

The sign-in token and any statistics are stored only on the owner's own computer. Nothing is sent to any server other than Google's own APIs.

Sharing

No data is sold, shared or passed to third parties. No data is used for advertising.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections. Revoking it invalidates the stored token immediately.

Contact

Questions: open an issue at github.com/rlunder/rednull.
